### About Me

I'm a final-year Computer Science & Engineering student at **United International University (UIU)**, currently in my 10th trimester. I like building things, figuring out how they work, and finding ways to make them better.

Most of my work so far has been in web development — building full-stack applications with React, Next.js, and Node.js. But I'm also spending more time exploring other areas that interest me, especially cybersecurity and AI/ML, which I'm studying through my university courses.

I'm still figuring out where I want to specialize, and honestly, that's part of the fun.

- **Currently exploring:** Linux, Cybersecurity, AI, and Machine Learning
- **Working with:** React, Next.js, TypeScript, Node.js, and related tools
- **Learning:** Application security, networking fundamentals, Linux
- **Interested in:** Software quality, system design, security, and practical problem-solving
